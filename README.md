# Python Data Structures & Algorithms for Data Science

Focused practice repository for the algorithms and data structures most relevant to Data Science interviews and efficient data processing.

## Topics Covered

- Arrays & Hashing
- Two Pointers / Sliding Window
- Trees & Binary Search Trees
- Graphs (basic BFS/DFS)
- Sorting & Searching
- Dynamic Programming (selected classic problems)
- Complexity analysis (Big-O) with DS examples
